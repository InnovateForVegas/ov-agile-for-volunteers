# Blue Sky - Agile for Volunteers - Initiative Tools

Where an organization and a component project repository are administrative entities (eg there can exist a GitHub organization or a nonprofit organization, and there can exist a git or svn repository), the Agile for Volunteers Initiative is more an administrative concept, which itself needs administrative tooling. The Initiative is an essential component, and must interoperate with organization and component project elements, making the tooling for administration of Initiatives necessarily aware of how these other elements are organized and administered themselves.
